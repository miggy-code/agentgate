# SOP: Refill reminder procedure

Refill reminders are a courtesy service. Customers opt in at checkout or by asking customer care.

## Weekly run (Monday morning)

1. Customer care opens the refill list for the coming two weeks.
2. For each customer, check that the opt-in is still on file and the email address is valid.
3. Send the standard reminder template from the care mailbox. Do not add any product advice to the message.
4. Mark the reminder as sent on the list.

## Replies

- "Yes, send it": create the order and flag it for fulfillment.
- "Pause": move the next reminder out by 30 days.
- "Stop": remove the customer from the list the same day.

Refill schedules are stored with the order records and are only visible to the manager and the owner.
